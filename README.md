# Python Module 1 — Final Project

## Название
Накопления на покупку

## Назначение
Программа рассчитывает накопления за 6 месяцев, долю от стоимости
покупки, недостающую сумму или остаток и выводит статус достижения цели.

## Вариант
Вариант №7: Накопления на покупку

## Используемые темы Python
- Ввод/вывод, типы int, float, str, bool
- Операторы и составные выражения
- Условия if–elif–else, логические and/or/not
- Цикл for с range()
- Цикл while (проверка ввода и повтор программы)
- Функции с параметрами и return
- f-строки и форматирование
